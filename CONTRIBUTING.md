# Contributing Guidelines

Thank you for considering contributing to this project for SE212! Here's how you can help.

## How to Contribute

1. Fork the repository
2. Create a new branch (`git checkout -b feature/feature-name`)
3. Follow setup instructions in the README
4. Make your changes
5. Commit your changes (`git commit -m 'Add some feature'`)
6. Push to the branch (`git push origin feature/feature-name`)
7. Create a Pull Request

## Pull Request Guidelines

- Provide a clear title and description
- Include any relevant issue numbers
- Follow existing code style and conventions

## Code Style

- Follow the existing code formatting
- Write clear, descriptive commit messages
- Comment your code when necessary
- Write documentation for new features

## Reporting Issues

- Use the issue tracker
- Describe the bug or feature request clearly
- Include steps to reproduce for bugs
- Include screenshots if relevant
